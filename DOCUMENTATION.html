2. Installation

Step-by-Step Installation Guide

  1. Upload Theme

    Log in to your Shopify admin panel, navigate to Online Store > Themes, click "Add theme" > "Upload zip file", and select the theme zip file.

  2. Customize Theme

    Click "Customize" on the uploaded theme, configure your logo, colors, and fonts, add your content to sections, and save your changes.

  3. Publish Theme

    Click "Actions" > "Publish" to make the theme live on your store.

✓ Success! Your Fragrance Boutique theme is now installed and ready to use.

Header Section

The header contains your site navigation, logo, search, and cart functionality. It features a sticky design that remains visible when scrolling.

Features:

  • Live cart count updates (automatically refreshes when items are added)
  • Sticky header on scroll
  • Mobile search toggle
  • Customizable contact information bar
  • Responsive hamburger menu for mobile

Customization Options:

  • Upload custom logo
  • Select navigation menu
  • Toggle contact info display
  • Set email address
  • Set phone number

Featured Products Section

sections/featured-products.liquid

Display a curated selection of products from any collection with filtering and add-to-cart capabilities.

Features:

  • Product filtering by categories/tags
  • Quick add to cart from grid
  • Hover effects on product cards
  • Sale badge for discounted items
  • Vendor/brand display

Customization Options:

  • Heading text
  • Subheading text
  • Collection selection
  • Number of products (4-24)
  • Enable/disable category filters
  • Show/hide "load more" button

Collection Section

sections/collection.liquid

Display all products in a collection with advanced filtering, sorting, and pagination.

Filter Options:

  • Price Range: Dual slider for min/max price
  • Availability: In stock / Out of stock
  • Brand/Vendor: Filter by product vendor
  • Product Type: Filter by product category
  • Tags: Filter by product tags

Sort Options:

  • Featured
  • Best Selling
  • Alphabetical (A-Z, Z-A)
  • Price (Low to High, High to Low)
  • Newest

Brands List Section

sections/brands-list.liquid

Automatically displays all unique brands/vendors from your store's products in an organized grid layout.

Features:

  • Automatic brand collection from all products
  • Product count per brand
  • Grid layout with brand images
  • Links to filtered collection view
  • Alphabetical sorting
  • Fully responsive design

How to Use:

  1. Go to Shopify Admin > Pages > Add page
  2. Create a page (e.g., title: "Our Brands")
  3. In the template selector, choose "page.brands"
  4. Save the page - brands will automatically populate

8. Troubleshooting

Common Issues & Solutions

Issue: Cart count not updating after adding products

Solution: This has been fixed in version 1.0.0. The header now listens for cart:updated events and automatically refreshes the cart count. If you're still experiencing issues:

  • Clear your browser cache
  • Ensure JavaScript is enabled
  • Check browser console for errors
Issue: Mobile menu not opening

Solution:

  • Ensure JavaScript is enabled in browser settings
  • Clear browser cache and cookies
  • Try a different browser to isolate the issue
  • Check if any third-party apps are conflicting
Issue: Products not displaying in featured products section

Solution:

  1. Ensure you've selected a collection in section settings
  2. Verify the collection has published products
  3. Check product availability (in stock vs out of stock)
  4. Ensure products are not archived
Issue: Filters not working on collection page

Solution:

  • Clear browser cache completely
  • Ensure products have vendor, type, and tag information
  • Check that JavaScript is not blocked by ad blockers
  • Verify browser compatibility (use latest version)
Issue: Brand page showing no brands

Solution:

  1. Ensure products have vendor/brand information filled in
  2. Products must be published and available
  3. Check that products are in the "all" collection
  4. Refresh the page or clear cache
  5. Verify the template is set to "page.brands"
Issue: Images not loading or appearing blurry

Solution:

  • Check image file sizes (recommend under 2MB per image)
  • Use recommended dimensions: 2048x2048px for product images
  • Ensure images are uploaded correctly in Shopify admin
  • Use JPG format for photos, PNG for logos/graphics
  • Clear Shopify CDN cache if issues persist

Performance Optimization Tips

  • Optimize images before uploading (use tools like TinyPNG)
  • Limit the number of sections on homepage (8-10 max)
  • Use Shopify's built-in image CDN (automatic)
  • Enable lazy loading for images (built-in)
  • Minimize use of heavy third-party apps
  • Regularly clean up unused products and collections
