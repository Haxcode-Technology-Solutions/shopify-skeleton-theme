                              1. INTRODUCTION
================================================================================

Fragrance Boutique is a modern, responsive Shopify theme designed specifically
for fragrance, perfume, and beauty product stores. Built with performance and
user experience in mind, this theme provides a clean, elegant interface that
showcases your products beautifully.

Key Highlights:
- Fully responsive design (mobile, tablet, desktop)
- Optimized for performance
- Easy to customize through Shopify theme editor
- Built-in cart functionality with live updates
- Advanced filtering and sorting
- Brand showcase capabilities
- SEO-friendly structure

================================================================================
                              2. INSTALLATION
================================================================================

STEP 1: Upload Theme
1. Log in to your Shopify admin panel
2. Navigate to Online Store > Themes
3. Click "Add theme" > "Upload zip file"
4. Select the theme zip file and upload

STEP 2: Customize Theme
1. Click "Customize" on the uploaded theme
2. Configure your logo, colors, and fonts
3. Add your content to sections
4. Save your changes

STEP 3: Publish Theme
1. Click "Actions" > "Publish" to make the theme live
2. Your store will now use the Fragrance Boutique theme

                              7. TEMPLATE USAGE
================================================================================

AVAILABLE TEMPLATES:

1. index.json - Homepage template
   Usage: Default homepage layout
   Sections: Hero, featured products, brand carousel, custom content

2. collection.json - Collection page template
   Usage: Product listing pages
   Features: Filtering, sorting, pagination

3. product.json - Product page template
   Usage: Individual product pages
   Features: Image gallery, variants, add to cart

4. page.json - Standard page template
   Usage: About, Contact, FAQ pages
   Features: Flexible content blocks

5. page.brands.json - Brands listing template
   Usage: Display all brands
   How to use:
   - Create a new page in Shopify admin
   - Set page handle to "brands" or any custom name
   - Select "page.brands" template
   - Page will automatically list all brands

6. cart.json - Cart page template
   Usage: Shopping cart display
   Features: Line items, totals, checkout

7. blog.json - Blog listing template
   Usage: Blog archive pages

8. article.json - Blog post template
   Usage: Individual blog posts

9. search.json - Search results template
   Usage: Product search results

10. 404.json - Error page template
    Usage: Page not found errors

                              8. TROUBLESHOOTING
================================================================================

ISSUE: Cart count not updating after adding products
SOLUTION: This has been fixed in the latest version. The header now listens
for cart:updated events and automatically refreshes the cart count.

ISSUE: Mobile menu not opening
SOLUTION: Ensure JavaScript is enabled. Clear browser cache and try again.

ISSUE: Products not displaying in featured products section
SOLUTION:
1. Ensure you've selected a collection in section settings
2. Verify the collection has products
3. Check product availability

ISSUE: Filters not working on collection page
SOLUTION:
1. Clear browser cache
2. Ensure products have vendor, type, and tag information
3. Check that JavaScript is not blocked

ISSUE: Brand page showing no brands
SOLUTION:
1. Ensure products have vendor information filled in
2. Products must be in the "all" collection
3. Refresh the page

ISSUE: Images not loading
SOLUTION:
1. Check image file sizes (recommend under 2MB)
2. Ensure images are uploaded correctly
3. Clear CDN cache

ISSUE: Search not working
SOLUTION:
1. Verify search is enabled in theme settings
2. Check that products have titles and descriptions
3. Ensure search input has proper name="q" attribute
